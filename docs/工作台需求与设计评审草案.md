## 已确认的范围与验收

评审输入自然语言需求，看到真实的生成阶段，并在同一页操作工具。首版生成内联 HTML、CSS、JavaScript 的独立单页，覆盖清单、看板和计算器等场景。「缺陷分诊板」可作为示例提示词。工作台同时展示一个工具，刷新后恢复本浏览器最近打开的工具及其数据。下一版的账号流程、「我的工具」和继续修改以[实施计划](实施计划.md#下一版账号流程我的工具与继续修改)的 AC-004 至 AC-007 为准。多 Agent 和用户可见的版本回滚留待后续。

## 技术约束与建议实现

### 生成接口与输出 · AC-001

- **已确认。** 工作台由仅监听本机的服务调用 DeepSeek。Key 仅来自本机或服务端配置，浏览器只看到配置是否可用。输入是自然语言，输出是自包含的完整 HTML，CSS、JS 内联，状态型工具使用约定的 `localStorage` 接口。模型调用日志和生成产物留在本机 `runs/`。 [DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)
- **接口建议。** `GET /api/config` 返回 `configured`。`POST /api/generate` 接收 `{requirement}`，通过检查后返回 `{id, html}`。恢复时以 `GET /api/tools/{id}` 读取同形 JSON。错误返回稳定的 `code` 和可展示的 `message`。生成请求限同源且只接受 JSON，恢复查询只接受受控工具 ID，生成 HTML 通过数据接口交付给隔离预览。每个成功产物有独立 ID。
- **最小检查建议。** 沿用 `deepseek-flash` 的单次非流式请求和已有响应检查，要求 `finish_reason=stop`、完整 HTML，并拒绝泄露凭据的响应。完整包裹的单层 HTML 代码围栏可先剥除。保留两道门槛，服务端确认产物完整，工作台确认候选预览和存储桥初始化。初始化就绪只表示能进入预览，具体操作结果由验收断言确认。

### 隔离预览与数据 · AC-002

- **已确认。** 模型 HTML 只在无同源权限的 sandbox iframe 中执行。CSP 限制资源加载和网络连接。工具文件保存在 `runs/`，浏览器保存最近工具引用与按工具区分的数据。旧样例的隔离依赖不同端口和测试侧请求白名单，本轮须重新验证正式工作台的配置。
- **隔离建议。** 以 sandbox `srcdoc` 为候选，允许脚本。若要支持表单提交事件，可加 `allow-forms`，同时以 `form-action 'none'` 阻止真实表单导航。保持 opaque origin、禁止顶层跳转和弹窗。预览 CSP 先于模型内容生效，以 `default-src 'none'`、`connect-src 'none'`、`base-uri 'none'` 和明确的脚本、样式策略约束资源。另验证宿主对 iframe 目标的限制，覆盖 iframe 自身跳转和嵌套加载。用可达的 HTTP 探针验证请求未到达服务端，避免把 DNS 或测试工具拦截误记为工作台通过。 [HTML iframe sandbox](https://html.spec.whatwg.org/multipage/iframe-embed-object.html#attr-iframe-sandbox) · [CSP](https://www.w3.org/TR/CSP3/)
- **存储建议。** 在模型脚本执行前注入当前工具的数据快照与 `localStorage` 兼容层，优先支持 `getItem`、`setItem`、`removeItem`、`clear`。父页处理消息时校验 `event.source` 为登记的窗口、opaque origin、当次预览实例标识、消息结构和大小。工具 ID 由父页绑定。桥接只允许访问本工具的键值，`clear` 也限定在本工具。候选在切换前只写暂存数据，废弃 iframe 的消息丢弃。存储失败给出提示，避免显示已保存。 [HTML Web Messaging](https://html.spec.whatwg.org/multipage/web-messaging.html#security-postmsg)
- **失败与切换。** 已确认失败保留旧可用结果。建议把旧预览和最近工具引用保留到候选通过检查且新引用保存成功，再切换。模型超时、无效输出、预览初始化失败或写入失败时，保留旧工具、旧数据及输入，允许重试。建议同一标签页只受理一笔生成。生成中刷新只恢复最后一次已确认工具。新工具成功后切换最近引用，旧数据按 ID 保留。首版没有历史列表入口。
