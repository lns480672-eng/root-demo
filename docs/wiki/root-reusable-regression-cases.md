# ROOT 可复用回归用例

设计下一轮回归时，先按改动命中下面的触发条件，再对照本轮 AC 和候选用例表。记录的版本是已验证的范围。

## 修改失败或取消后恢复原工具和数据

- **触发条件**：改续改任务、候选预览、源码视图、版本历史或保存事务。关联 AC-005、AC-007、AC-008。
- **步骤和预期**：准备已有记录和已应用版本的工具。生成候选并核对预览和源码对应同一候选。分别取消与注入失败，核对两个视图均回到正式版，历史和正式记录保持原样。另走确认应用路径，核对仍是同一工具、恰好新增一个版本、刷新后旧记录与新版均可读。检查另一普通账号读不到该工具源码。
- **原始依据**：`specs/revision-workspace-views/test-design.md` 的 RVIEW-03、RVIEW-04、RVIEW-06。候选 `c27d5b0` 的正式用例及通过回执在 `runs/owner-feedback-2026-11-14/revision-workspace-views/integration-c27d5b0/`。

## 生成历史归属与失败恢复

- **触发条件**：改新建历史、修改对话、任务筛选、恢复入口或任务权限。关联 AC-018-B2。
- **步骤和预期**：用两个账号、每账号独立工具及交错的新建和修改任务。新建历史只返回本账号符合条件的最新 30 条新建任务，修改历史按工具归属，跨账号读取被拒。把失败原文带回正确的新建或修改入口；打开、恢复、刷新期间核对未派发、未扣次，显式提交后才产生正确归属的新任务。运行中或保存待确认的任务继续核对原任务 ID。
- **原始依据**：`specs/generation-history-ownership/test-design.md` 的 HISTORY-01 至 HISTORY-04。候选 `56781ec` 的正式用例及通过回执在 `runs/feedback-2026-11-14/history-ownership/`。

## 注册邀请码到期边界和旧码保留

- **触发条件**：改默认有效期、发码、升级迁移或注册校验。关联 AC-004、AC-019。
- **步骤和预期**：用受控服务端时钟验证默认新码有效期为生成后 259200 秒，到期前一秒允许注册并消费一次，到期当秒拒绝且不创建账号、不消费。有效期内已用掉的单次码也应拒绝。候选打开旧库后对照旧码原有到期时间和次数，并按旧码的原边界实际注册。
- **原始依据**：`specs/invite-validity/test-design.md` 的 INVITE-72H-01 至 INVITE-72H-04。候选 `18b2be6` 的正式用例、QA 和产品通过回执在 `runs/owner-feedback-2026-11-14/invite-72h/`。
