## 范围

REQ-AGENT-01 在 `codex/coding-agent-refactor` 的独立本机工作台试用。沿用自然语言输入。新建和继续修改的实现步骤都由 Pi Agent Core 调用 DeepSeek Flash 执行。参考调研提交 `75588a1`，产品代码基线为 `b924d56`。试用实例初始化独立数据库，账号、工具、记录和调用日志使用独立目录。试用期间产生的数据须能保存和恢复。旧库迁移、公网部署、通用多文件运行环境及外部服务属于后续范围。

REQ-AGENT-02 修改以当前已保存的源码为起点。涉及可空字段类型且用户未说清时，先澄清。生成候选后可预览和取消，确认后才更新同一工具。修改生效时应保留此前保存的记录，并能检测基准版本或记录在确认期间的变化。沿用 AC-001、AC-002、AC-007、AC-018-B、AC-018-C。

REQ-AGENT-03 每轮模型请求由宿主计数。Agent 的工具限定为当前候选的读写及受控检查。宿主校验候选源码和运行结果，确认绑定候选和当前版本。失败、超时、超额及校验拒绝显示在同一任务，已保存工具仍可使用。

REQ-AGENT-04 修改已保存工具的记录或字段结构时，系统先生成可校验的变更方案。服务端根据当前数据计算影响，在确认前列出操作、字段、受影响记录数及变更示例。用户确认当前方案后，服务端执行并保存；取消、校验失败或记录已变化时，原数据与工具版本保持可用。工具的业务数据范围限定在当前账号、当前工具内。

## 接入与执行

| 技术验收 | 通过条件 | 验证 |
| --- | --- | --- |
| TECH-AGENT-01 实际接入 | 从正式工作台新建及继续修改时，记录型工具、计算工具和官网的代码实现由 Pi Agent 调用 DeepSeek 产生；续改读取已保存源码。规格、导表与旧结构型续改的原路径有单独证据。 | 各类型浏览器流程、任务派发和候选源码。 |
| TECH-AGENT-02 配额和时间 | 启动配置可覆盖 Agent 运行时间和任务派发次数，任务执行权覆盖配置的运行时长。每个派发记入共享额度，个人只在结果保存或确认生效时记一次。 | 配置测试、预算耗尽和成功/取消回执。 |
| TECH-AGENT-03 受控数据变更 | Agent 提交结构化提案，宿主计算工具内的变更并绑定当前快照。记录变更和版本更新在同一事务；候选运行时只能试用。 | AC-AGENT-05，接口冲突、重复发布和浏览器确认。 |

- TASK-AGENT-01 在规格生成后接入 Agent 实现阶段，先用确定性模型响应验证代码能进入现有组装、预览和保存流程。首轮使用 HTML 片段、CSS、JS，沿用现有预览容器。
- TASK-AGENT-02 把实际已保存的源码交给 Agent。宿主校验生成结果、保留字段标识。沿用已有试用预览的隔离方式，将候选试用与确认应用分成两步。确认沿用现有版本绑定。验证 AC-AGENT-02、AC-AGENT-03 后再交用户试用。
- TASK-AGENT-03 复用宿主计量、浏览器隔离、版本冲突和失败恢复。Agent 只能操作允许的候选内容。按任务记录耗时、模型调用次数及失败原因。
- TASK-AGENT-04 固定试用提交和构建，启动独立本机入口，交付登录方式、两条起步需求和验证结果。
- TASK-AGENT-05 将 Agent 的结构化数据变更提案接入宿主影响计算和版本确认。用可执行回归覆盖未确认、确认、取消、异常值、重复确认及并发写入。

Claude Sonnet 评审建议由宿主负责隔离、计量及确认，Agent 负责候选源码。调研时的工作台单任务模型调用上限为 8 次，调研中 Pi 续改中位数为 9 次。首轮先测实际调用量，再为试用实例确定有界上限，发布给试用者前记录配置及超限结果。

## 生成调用与额度

2026-11-14，用户确认以下初始配置，适用于本机 Agent 试用和生产 Agent 工作台。

| 计量范围 | 默认上限 | 环境变量 | 计数规则 |
| --- | ---: | --- | --- |
| 单个生成或修改任务 | 100 次模型派发 | `ROOT_AGENT_MAX_MODEL_CALLS` | 同一任务累计，包括规格、实现、重试和恢复后的派发。第 101 次在请求模型前拒绝。 |
| 单个账号 | 1,000 次成功 | `ROOT_ACCOUNT_GENERATIONS` | 新建成功保存或修改确认生效时记一次。取消、失败、重放不新增成功次数。既有用量和补额保留。 |
| 全站共享 | 10,000 次模型派发 | `ROOT_TOTAL_GENERATIONS` | 所有账号共用，每次实际派发消耗一次，失败派发也计入。同一任务的派发同时计入其任务上限。达到上限时拒绝下一次派发。 |

额度沿用数据库累计记录，应用配置时不重置。环境变量可覆盖默认值，个人基础额度不得超过全站额度。Agent 单次运行时限独立控制，`ROOT_AGENT_TIMEOUT_SECONDS` 未配置时为 120 秒。验收核对本机与生产启动参数、100／101 次边界、两个账号的共享余额、已有用量及有效配置覆盖。一条真实场景用于检查正常生成或续改，不要求发出 100 次真实模型调用。
