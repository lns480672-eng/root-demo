## 范围

REQ-AGENT-01 在 `codex/coding-agent-refactor` 的独立本机工作台试用。沿用自然语言输入。新建和继续修改的实现步骤都由 Pi Agent Core 调用 DeepSeek Flash 执行。参考调研提交 `75588a1`，产品代码基线为 `b924d56`。试用实例初始化独立数据库，账号、工具、记录和调用日志使用独立目录。试用期间产生的数据须能保存和恢复。旧库迁移、公网部署、通用多文件运行环境及外部服务属于后续范围。

REQ-AGENT-02 修改以当前已保存的源码为起点。涉及可空字段类型且用户未说清时，先澄清。生成候选后可预览和取消，确认后才更新同一工具。修改生效时应保留此前保存的记录，并能检测基准版本或记录在确认期间的变化。沿用 AC-001、AC-002、AC-007、AC-018-B、AC-018-C。

REQ-AGENT-03 每轮模型请求由宿主计数。Agent 的工具限定为当前候选的读写及受控检查。宿主校验候选源码和运行结果，确认绑定候选和当前版本。失败、超时、超额及校验拒绝显示在同一任务，已保存工具仍可使用。

## 接入与执行

- TASK-AGENT-01 在规格生成后接入 Agent 实现阶段，先用确定性模型响应验证代码能进入现有组装、预览和保存流程。首轮使用 HTML 片段、CSS、JS，沿用现有预览容器。
- TASK-AGENT-02 把实际已保存的源码交给 Agent。宿主校验生成结果、保留字段标识，并用既有版本及确认机制应用候选。验证 AC-AGENT-02、AC-AGENT-03 后再交用户试用。
- TASK-AGENT-03 复用宿主计量、浏览器隔离、版本冲突和失败恢复。Agent 只能操作允许的候选内容。按任务记录耗时、模型调用次数及失败原因。
- TASK-AGENT-04 固定试用提交和构建，启动独立本机入口，交付登录方式、两条起步需求和验证结果。

Claude Sonnet 评审建议由宿主负责隔离、计量及确认，Agent 负责候选源码。当前工作台的单任务模型调用上限为 8 次，调研中 Pi 续改中位数为 9 次。首轮先测实际调用量，再为试用实例确定有界上限，发布给试用者前记录配置及超限结果。
