# 反馈 05 普通新建任务短标题

Ready。基础需求，关联 AC-001、AC-011。草稿短名沿用 AC-013。

点击「开始」后，普通新建在理解需求阶段由 AI 概括短标题，例如将包含费用规则和数据要求的长输入概括为「旅行分账」。理解完成前显示「新工具」。收到标题后，更新同一任务的进度区、任务列表和历史，原文可在详情展开。刷新或重开仍显示该标题。旧任务缺标题或命名失败时显示「新工具」，其余流程可继续。

从已命名草稿带入时，优先使用用户确认的草稿短名。保留完整需求、任务 ID 与原有保存流程。优先复用理解阶段已有标题，验收核对同一任务及实际派发次数。工具自身命名、历史归属和额度规则沿用各自规格。

[可交互原型](../../design/root-new-tool-review.html)使用读书清单、AA 分账及交付跟进板示例演示标题延迟返回。选一个示例并点开始，可看到标题更新，刷新可继续查看。如需演示缺名，可输入其他主题。
